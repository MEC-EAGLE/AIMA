# AIMA Setup Instructions

Follow these steps to run the project locally:

1. **Install dependencies**
   ```bash
   npm install
   ```
   Run this command inside the `myapp` folder.

2. **Start the database API**
   ```bash
   npm run server
   ```
   This launches a simple API on **port 3001**.

3. **Start the Vite frontend**
   ```bash
   npm run dev
   ```
   The application will be available in your browser.

## Tests

Execute `npm test` to run the current test script. It simply outputs `No tests implemented`.
